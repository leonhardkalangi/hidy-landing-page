Before the appointment

  1. Back up the iPhone and check iCloud finished syncing, as Apple describes.
  2. Back up each Hidy vault. In each vault's Settings, make sure iCloud backup is on, or export a backup file to a computer.
  3. Check you have every recovery phrase. Without them, a backup can't be opened.
  4. Move private photos out of Photos into a vault, then empty Recently Deleted.
  5. Follow Apple's Find My steps for your iOS version, such as Ready for Repair.

When you get it back

  • If it was erased, restore the iPhone from your backup or set it up as new.
  • Install Hidy Vault if needed, then choose Restore from iCloud or Restore from a backup file on the lock screen and enter each vault's phrase.
  • Don't delete old backups until every vault is back and checked.
