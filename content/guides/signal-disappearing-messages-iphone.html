What does a Signal disappearing message actually do?

Signal offers disappearing messages. That is a Signal feature. It is not something iOS does for other apps, and it does not change how Apple's Messages app works. If you want the exact behaviour, including how long the options are and what happens to media, read Signal's own support pages. This page covers the iPhone side.

Does Apple's Messages app have disappearing messages?

No. Apple documents sending, editing, unsending, deleting and filtering messages. There is no general setting that deletes ordinary texts on a timer.

Apple's manual route is short:

None of this is automatic. You have to do it, message by message or chat by chat.

What a disappearing message does not remove

This is the part people get wrong. A message leaving a chat is not the same as every copy of what it contained leaving the phone.

  • Screenshots. Anyone in the chat can screenshot before the timer ends.
  • Photos you saved elsewhere. If you saved an image to Photos, or imported it into another app, the timer in the chat does not reach it.
  • Backups. Whether a message appears in a device backup depends on the app and on your iCloud settings. Check Signal's documentation rather than assuming.

If the goal is that a photo should not be sitting in your camera roll at all, a chat timer is the wrong tool. The file needs to not be there in the first place.

Where do private photos fit in?

Photos you took, saved or received still live in Photos unless you move or delete them.

That is the gap Hidy Vault is built for. It is an encrypted vault app for iPhone, iOS 16 or later, coming to the App Store. You import photos and videos from Photos, or shoot with Hidy's own camera so the pictures never reach the Photos library. Contents, file names, thumbnails, folders and notes are encrypted with AES-256-GCM, and the key comes from a pattern you draw on a 5×5 grid plus a device secret in the iPhone Keychain.

Each valid pattern opens its own vault, so one pattern can hold work documents and another can hold personal photos. Hidy locks as soon as it goes to the background and covers the app switcher. There is no Face ID unlock for Hidy itself; the pattern is the way in.

Two honest notes. An open vault is readable on screen, so lock the phone when you put it down. And Hidy has no independent cryptographic audit yet.

Limits you should know before relying on any of this

  • Hidy cannot reset a forgotten pattern. Set up the 12-word recovery phrase for each vault you care about. It is shown once and reopens that vault if the pattern is lost.
  • Sharing out gives a readable copy. Once a file leaves Hidy, the recipient has it.
  • Storage inspection shows some shape. Someone examining the app's storage can see approximate file sizes and how many vault folders exist, not contents or names.

Disappearing messages are a good habit for conversations. They are not a photo locker. Use each tool for the job it was built for, and check the app's own documentation before you trust a timer with something that matters.
