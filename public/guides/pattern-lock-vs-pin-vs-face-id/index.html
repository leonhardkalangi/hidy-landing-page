Pattern lock vs PIN vs Face ID on iPhone

Updated 25 October 2026 · By Hidy

iPhone has no built-in pattern lock. You unlock it with a passcode (PIN or alphanumeric) and, on supported models, Face ID. Hidy Vault adds a 5×5 pattern for its encrypted vaults.

Quick answer
  • iPhone: no pattern lock. Use a passcode and Face ID.
  • Passcode: 6-digit default; custom numeric or alphanumeric in Settings.
  • Hidy Vault: draw a pattern on a 5×5 grid to open an encrypted vault.

Does iPhone have a pattern lock?

No. Apple documents two ways to unlock iPhone: a passcode and, on supported models, Face ID. There is no Android-style pattern lock in iOS. If you want a pattern, it has to come from an app.

Hidy Vault is one of those apps. It unlocks with a pattern drawn on a 5×5 grid, using at least 6 different dots. Each valid pattern opens its own vault. That pattern is not the iPhone lock screen; it protects files inside Hidy.

How does the iPhone passcode work?

The passcode is the base credential. Face ID cannot replace it entirely; Apple says Face ID requires a passcode. To set one, go to Settings > Face ID & Passcode, tap Turn Passcode On, and enter a six-digit passcode.

Tap Passcode Options to choose Custom Alphanumeric Code, Custom Numeric Code, or 4-Digit Numeric Code. The six-digit code is the default. Apple does not state a maximum length for custom codes.

To change it later, go to Settings > Face ID & Passcode > Change Passcode, enter the current code, then enter the new one twice.

There is a hard limit you can turn on. In Settings > Face ID & Passcode, enable Erase Data. After 10 consecutive incorrect passcode attempts, iPhone erases all content and settings.

How does Face ID fit in?

Face ID is a convenience layer on top of the passcode. Set it up in Settings > Face ID & Passcode > Set Up Face ID > Get Started. Put your face in the frame, move your head to complete the circle, tap Continue, repeat the scan, then tap Done.

Under Use Face ID For, you can enable it for iPhone Unlock, iTunes & App Store, Wallet & Apple Pay, Password AutoFill, and supported apps. If your face changes a lot, set an alternate appearance in Settings > Face ID & Passcode > Set Up an Alternate Appearance.

Face ID has its own limits. After five unsuccessful face-match attempts, iPhone requires the passcode. Apple also requires the passcode after a restart, after more than 48 hours without unlocking, and after a remote lock command. The same happens after initiating power off or Emergency SOS.

One setting matters for security. With Require Attention for Face ID on, iPhone unlocks only when your eyes are open and looking at the screen. Apple says requiring attention makes Face ID more secure.

The comparison is not quite fair, because they protect different things. The passcode and Face ID guard the whole iPhone. A Hidy pattern guards one encrypted vault inside the app.

Why use a pattern at all?

A pattern is fast to draw with one hand and easy to remember as a shape. In Hidy, the pattern is not just a screen lock. The pattern plus a device secret in the iPhone Keychain derive the encryption key. File contents, names, thumbnails, folders and notes are encrypted with AES-256-GCM.

That design has a practical consequence: each valid pattern opens a different vault. An unused pattern opens a new, empty vault that is saved only after you add the first item. There is no list of vaults and no wrong-pattern message.

You can change a vault's pattern in its Settings. Hidy cannot reset a forgotten pattern. That is what the 12-word recovery phrase is for: it reopens the vault so you can choose a new pattern.

When should you use each one?

  • Use a strong passcode as your base. A six-digit code is the default; a custom alphanumeric code is stronger if you can type it comfortably.
  • Use Face ID for daily speed, with Require Attention on. Keep in mind it falls back to the passcode after five failed attempts.
  • Use a Hidy pattern for files you do not want in the Photos library or the Hidden album. It keeps them behind a separate credential.
  • Store the recovery phrase for any vault you care about. Without it, a forgotten pattern means the vault stays closed.

What are the limits?

Hidy's pattern is not a replacement for your iPhone passcode. It protects vault contents, not the device. An open vault is readable on screen, and Hidy has no independent cryptographic audit yet. Someone examining the app's storage can see approximate file sizes and the number of vault folders, though not contents or names.

There is also no Face ID or Touch ID unlock for Hidy itself. The pattern is the way in. If you want to hide the app icon too, Hidy Pro offers Calculator, Notes, Weather or Tasks icons, but the name under the icon stays "Hidy Vault."

On the iPhone side, Face ID is convenient but not absolute. It requires the passcode after a restart, after five failed matches, and in the other cases Apple lists. Treat the passcode as the real key.

Frequently asked questions

Can I set a pattern lock on iPhone?

No. Apple documents only a passcode and Face ID for unlocking iPhone. A pattern lock is an Android feature. Hidy Vault uses a pattern, but only inside the app for its encrypted vaults.

Is Face ID more secure than a passcode?

They work together. Face ID requires a passcode as a fallback, and iPhone asks for the passcode after five failed face-match attempts. Apple says Require Attention makes Face ID more secure.

What happens after 10 wrong passcode attempts?

If you turn on Erase Data in Settings > Face ID & Passcode, iPhone erases all content and settings after 10 consecutive incorrect passcode attempts.

How do I quickly disable Face ID?

Press and hold the side button and either volume button for 2 seconds. When the sliders appear, press the side button to lock iPhone. Face ID works again after the next passcode unlock.
