How to transfer a photo vault to a new iPhone

Updated 22 October 2026 · By Hidy

Back up each vault on the old iPhone, then on the new one choose Restore from iCloud or Restore from a backup file on Hidy's lock screen and enter that vault's recovery phrase. Check every vault opens before you erase the old phone.

Quick answer
  • Old iPhone: make sure each vault has a recovery phrase and an iCloud backup or a backup file.
  • New iPhone: Hidy lock screen > Restore from iCloud or Restore from a backup file > enter the phrase > choose a pattern.
  • Repeat for every vault, then open each one before erasing the old iPhone.

On the old iPhone

  1. Open each vault and go to Settings.
  2. Create a recovery phrase if it doesn't have one, and write it down.
  3. Turn on iCloud backup, or export a backup file to Files, iCloud Drive, a Mac or AirDrop it to the new phone.
  4. Wait until the backup completes.

On the new iPhone

  1. Install Hidy Vault.
  2. On the lock screen, open the options and choose Restore from iCloud or Restore from a backup file.
  3. Pick the backup, enter the vault's 12 words, and choose a pattern.
  4. Repeat for each vault.

Before you erase the old iPhone

  • Open every vault on the new iPhone and view a few files.
  • Keep the old iPhone and the backups until you've checked.
  • Then follow before you sell your iPhone.

Frequently asked questions

Does the iPhone migration bring my vaults?

Don't rely on it. Use Hidy's own backup and restore with the recovery phrase; it's the path Hidy is designed for.

Do I need the same Apple Account?

To restore from iCloud, the new iPhone needs access to the iCloud account that holds the backup. A backup file works with any account.

Can I keep the vault on both phones?

Yes, with Pro, turn on sync and the vault stays current on both.
