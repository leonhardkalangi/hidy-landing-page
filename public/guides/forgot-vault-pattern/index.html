Forgot your vault pattern? What you can still do

Updated 22 October 2026 · By Hidy

First, make sure it's really forgotten: a slightly different pattern opens an empty vault, not an error. If it is, choose the recovery-phrase option on Hidy's lock screen and enter the vault's 12 words. Without the pattern or the phrase, nobody can open that vault.

Quick answer
  • An empty vault isn't a lost vault. You probably drew a slightly different pattern. Your files are behind the exact one.
  • Check the grid size: vaults made with the old 4×4 prototype need Legacy mode.
  • Still stuck? Lock screen > recovery option > enter the 12 words > choose a new pattern.

1. Rule out the easy causes

  • Empty vault? Hidy doesn't show a wrong-pattern error. Any valid pattern you haven't used opens a new, empty space. Seeing an empty vault means "not this pattern", not "your files are gone".
  • Same start point and direction? Patterns are paths. Starting from the other end is a different pattern.
  • Right grid? The default grid is 5×5. Vaults created with the earlier 4×4 prototype open only in Legacy mode, which you can choose on the lock screen.
  • Tap mode? If you set up the vault by tapping dots, tap them in the same order.

2. Use the recovery phrase

  1. On Hidy's lock screen, open the options and choose the recovery-phrase option.
  2. Enter the vault's 12 words in order.
  3. Choose a new pattern. Write down a hint that only you understand, not the pattern itself.

3. If you have no phrase

Then the vault can't be opened. Hidy's encryption is built so that no one else holds a key, and that includes us. Backups need the same phrase. This is the trade-off for a vault nobody can open behind your back.

Don't make it worse

  • Don't uninstall Hidy. Removing the app can remove the local vaults and the device secret they rely on.
  • Don't reset the iPhone while you're still trying patterns.

Next time

Create a recovery phrase for every vault on the day you make it, and keep it on paper away from the phone.

Frequently asked questions

Can Hidy support reset my pattern?

No. There's no account and Hidy keeps no copy of your pattern. Only the vault's recovery phrase can reopen it.

I have a backup but no phrase. Can I restore it?

No. A backup opens only with the recovery phrase of the vault it came from.

Will trying many patterns lock me out?

Hidy has no wrong-pattern lockout, because any valid pattern opens a vault. Each new pattern you try just opens an empty space.

Should I reinstall Hidy?

No. Deleting the app can delete the local vaults and the Keychain secret they depend on. Don't uninstall to troubleshoot.
