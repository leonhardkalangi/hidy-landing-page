Your first encrypted vault in Hidy

Updated 22 October 2026 · By Hidy

A pattern opens a space. Files you add are encrypted inside it.

Install Hidy Vault for iPhone and open it. There is no account or email to set up.

Choose a pattern you can remember

On the default 5×5 grid, connect at least six distinct dots. Draw the same pattern with the same grid to reopen the same vault. Tap controls are available if drawing is difficult.

A different pattern opens a different, empty space. This does not mean your original files disappeared. Return to the exact pattern and grid you used before. Existing vaults made with the older 4×4 grid retain their original input mode.

Add photos, videos or documents

Use the import controls to select from Photos or Files. You can also use the in-app camera, create a folder or write a note. Hidy encrypts the imported copies, including their names and thumbnails.

Comparing options first? See how to lock photos on iPhone with the Hidden album, a locked Photos app or a vault.

Want photos your iPhone passcode can't open?

Hidy Vault keeps photos, videos and documents in encrypted vaults that open only with a pattern you draw. No account, no Hidy server. Free for 3 vaults.

Decide what to do with originals

Importing does not automatically remove the source file. If you choose to delete originals from Photos, iOS asks for permission and confirmation. Apple's Recently Deleted album, other backups and other copies may still contain the original.

Lock and reopen

Tap Lock to end the session. Hidy also locks when backgrounded. Reopen with the same pattern. No cross-vault list is shown on the lock screen, but this is an interface behavior, not a guarantee that vault storage is invisible on disk.

Save a recovery phrase before you need it

Create the vault's recovery phrase in Settings and keep it privately outside the app. Then make an encrypted backup. Your pattern is not a substitute for the phrase when restoring a backup onto another device.
