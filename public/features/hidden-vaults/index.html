Hidden vaults: a separate space for every pattern

Updated 22 October 2026 · By Hidy

Every valid pattern in Hidy Vault opens its own encrypted vault. There's no list of vaults on the lock screen and no wrong-pattern error, so the app itself doesn't reveal how many vaults you have.

Quick answer
  • A new pattern opens a new, empty vault. The same pattern always reopens the same vault.
  • Hidy shows no vault list and no wrong-pattern message.
  • Free: 3 vaults with 100 photos and 10 videos each. Pro: unlimited.

Why separate vaults matter

Not everything private is private from the same person. Work documents, medical records, ID scans and personal photos have different audiences. With one vault and one code, opening it for one reason shows everything. With separate vaults, you only open the one you need.

How it works

Hidy derives a vault's key from its pattern (see pattern encryption). A different pattern derives a different key, and a different key opens a different space. There's no master list of vaults that the app shows or that you have to unlock first.

  • No list on the lock screen. Hidy opens straight into a pattern grid.
  • No error for a "wrong" pattern. Any valid pattern opens something. An unused one opens an empty vault.
  • Each vault has its own settings: its own recovery phrase, its own iCloud backup switch, and its own sharing.

A typical setup

  1. Everyday vault: screenshots, receipts, photos you just don't want in your camera roll.
  2. Documents vault: passport, ID, insurance and tax papers, imported from Files.
  3. Personal vault: the photos you'd least want anyone to see, with a pattern you don't use anywhere else.

That's exactly the free plan's 3 vaults. Pro removes the limit if you need more.

Limits to know

  • This is not invisibility on disk. The lock screen hides which vaults exist, but someone examining the app container can see roughly how many vault folders there are and their sizes. Contents and names stay encrypted.
  • A forgotten pattern isn't a "wrong" pattern. If you draw something slightly different, you'll see an empty vault, not an error. Your files are still behind the exact pattern you used.
  • Each vault needs its own recovery phrase. One vault's phrase doesn't open another.

Make a second vault

  1. Lock Hidy.
  2. Draw a new pattern you haven't used before. Hidy opens an empty vault.
  3. Import what belongs there, then create this vault's recovery phrase in Settings.

Frequently asked questions

How many vaults can I have?

The free plan includes 3 vaults, each with up to 100 photos and 10 videos. Pro removes the vault, photo and video limits.

What happens if I draw a pattern I've never used?

Hidy opens a new, empty space for that pattern. It doesn't warn you, which is why a mistyped pattern can look like your files disappeared. Draw the exact pattern again and they're there.

Can someone tell how many vaults I have?

Not from the app's screens. Someone who can examine the app's storage on the device can see roughly how many vault folders exist and their approximate sizes, but not their contents.

Does opening a new pattern by mistake create clutter?

No. An unknown pattern opens an empty vault that is only saved once you add the first item to it.
